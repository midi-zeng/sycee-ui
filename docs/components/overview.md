# Components

Sycee UI ships **24 components** in both `@sycee-ui/react` and `@sycee-ui/vue`,
sharing one stylesheet and one design language.

## General

| Component | Description |
| --- | --- |
| [Button](/components/button) | Clickable actions in 5 colors × 5 variants |
| [Icon](/components/icon) | Inline SVG icon set |
| [Card](/components/card) | Bordered content container with header/footer |
| [Tag](/components/tag) | Small status/purpose label |
| [Avatar](/components/avatar) | Image or initials, with group overlap |
| [Badge](/components/badge) | Count / dot status pinned to wrapped content |
| [Divider](/components/divider) | Horizontal / vertical separator with label |
| [Empty](/components/empty) | Empty-state placeholder with illustration |
| [Space](/components/space) | Flex layout with consistent gaps |

## Data entry

| Component | Description |
| --- | --- |
| [Input](/components/input) | Text input with prefix/suffix and clearable |
| [Textarea](/components/textarea) | Multi-line text input with counter |
| [Select](/components/select) | Keyboard-accessible single select |
| [Checkbox](/components/checkbox) | Checkboxes and checkbox groups |
| [Radio](/components/radio) | Radios and radio groups |
| [Switch](/components/switch) | Boolean toggle |

## Feedback

| Component | Description |
| --- | --- |
| [Alert](/components/alert) | Inline callouts for info/success/warning/danger |
| [Message](/components/message) | Imperative toast notifications |
| [Modal](/components/modal) | Accessible dialog with focus management |
| [Tooltip](/components/tooltip) | Hover/focus/click hint with smart placement |
| [Spinner](/components/spinner) | Loading indicator |
| [Progress](/components/progress) | Determinate and indeterminate progress bars |

## Navigation & data display

| Component | Description |
| --- | --- |
| [Tabs](/components/tabs) | Animated underline tabs with keyboard support |
| [Pagination](/components/pagination) | Page navigation with ellipsis ranges |
| [Table](/components/table) | Lightweight data table with striped/bordered modes |

::: tip
Every page shows live demos for **both frameworks** — flip the Vue/React tabs on
any demo block to compare the two APIs.
:::
