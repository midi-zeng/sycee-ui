# Components

Sycee UI ships **50 components** in both `@sycee-ui/react` and `@sycee-ui/vue`.
They share one stylesheet, one visual language, and one set of accessibility
patterns.

## General

| Component | Description |
| --- | --- |
| [Button](/components/button) | Action buttons in five colors and variants |
| [Copy](/components/copy) | Clipboard action with success and error feedback |
| [Watermark](/components/watermark) | Repeating text or image watermark for content areas |
| [Icon](/components/icon) | Lightweight inline SVG icons |
| [Card](/components/card) | Content container with optional header and footer |
| [Tag](/components/tag) | Compact status or category label |
| [Avatar](/components/avatar) | Image, initials, and overlapping groups |
| [Badge](/components/badge) | Count or dot status on wrapped content |
| [Divider](/components/divider) | Horizontal or vertical separator |
| [Empty](/components/empty) | Empty-state illustration and message |
| [Space](/components/space) | Consistent flex spacing |
| [Skeleton](/components/skeleton) | Loading placeholders |
| [NinePatch](/components/nine-patch) | Stretchable nine-patch images |

## Utilities

Framework-agnostic helpers such as date and number formatting are available in
[`@sycee-ui/utils`](/utils/overview) and are re-exported from both framework
packages.

::: tip
Every page includes live Vue and React demos. Choose the framework tab to
compare equivalent APIs.
