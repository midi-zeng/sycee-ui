# 组件

Sycee UI 在 `@sycee-ui/react` 与 `@sycee-ui/vue` 中同步提供 **50 个组件**。
两端共享同一份样式、视觉语言和无障碍交互模式。

## 通用

按钮、复制、水印、图标、卡片、标签、头像、徽标、分割线、空状态、间距、骨架屏和九宫格图。

## 数据录入

输入框、文本域、数字输入框、选择器、复选框、单选框、开关、评分、滑块、
日期选择器、级联选择、树形控件、上传和表单。

## 反馈

警告提示、全局提示、通知、对话框、抽屉、文字提示、气泡确认、加载中、
进度条、结果页和图片。

## 导航

面包屑、标签页、分页、步骤条、下拉菜单和折叠面板。

## 数据展示

表格、时间线、无限加载、轮播、跑马灯和弹幕。

## 动画与时间

倒计时组件支持自定义时间格式、盒式数字显示和完成回调。

## 工具

[`@sycee-ui/utils`](/zh/utils/overview) 提供无框架依赖的日期和数字格式化能力，
同时从 React、Vue 包中再次导出。

::: tip
每篇组件文档都提供 Vue 与 React 实时示例。切换框架标签可以对照两端 API。
:::
